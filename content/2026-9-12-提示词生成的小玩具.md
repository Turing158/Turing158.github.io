# 提示词生成的小玩具

目前通过提示词生成了六种主题的小玩具：**building（体素建筑工地）**、**shop-rainning（雨夜便利店街角）**、**gardon（湖畔花园）**、**lego（多层积木小城）**、**beijing-temple-of-heaven-gpt6astra（北京天坛祈年殿）** 与 **whale（云鲸渡）**，共 11 个模型版本。建筑工地有 2 个版本，雨夜便利店有 4 个版本，湖畔花园有 2 个版本，其余主题各 1 个。不同版本既是独立可玩的小场景，也提供了观察各模型如何处理场景、动效和交互的机会。

这一轮收录的五个版本包括 `shop-rainning-ds41f`、`gardon-ds41f`、`lego-gpt6astra`、`beijing-temple-of-heaven-gpt6astra` 和 `whale-gpt6astra`：从带可折叠设置条的雨夜街角、可调四季的桌面花园，到透明盒中的积木小城、可逐层拆解的祈年殿，以及在巨鲸背上穿行云海的小镇。

## 一、building · 体素建筑工地沙盘

### 主题概述

`building` 主题的提示词要求:用 WebGL(Three.js r160)创作一个**体素微缩建筑工地沙盘**,输出为可直接在浏览器打开的单个 HTML 文件,不引用任何外部素材,全部几何体、材质、贴图用代码程序化生成,并要求稳定 60FPS、杜绝穿模。

场景设定颇有巧思:整套工地微缩模型摆放在**室内深色实木工作桌**上,桌角散落蓝图图纸、钢卷尺、安全帽摆件和金属水平仪,观察者以第三人称平视的"人眼高度"打量这个沙盘——像一个被定格的手办世界。

工地本体划分为多个功能区:基坑开挖区、钢筋加工棚、物料堆放区、在建高层楼房基座、临时板房办公区、渣土堆放区和临时施工道路。同时要求大量动态机械与人物:挖掘机持续挖土装车、渣土卡车循环接土卸料、塔吊回转吊运钢筋与混凝土料斗、搅拌罐车与装载机穿梭其间,二十余名体素工人各司其职,安保人员巡逻。这是一份对**场景调度、动画状态机和性能优化**要求都很高的提示词。

### 模型版本对比

#### `building-glm53f` — 体素建筑工地 · 微缩沙盘

glm53f 版本是一个约 92KB 的单文件实现,对提示词的还原非常"工程化":

- **完整的功能分区**:基坑开挖、钢筋加工棚、物料堆放、在建楼房基座、临时板房办公区、渣土堆放区、施工道路与围挡大门全部到位,布局紧凑合理。
- **机械动画有真实逻辑**:挖掘机采用解析 IK(逆运动学)驱动铲斗挖掘土方,渣土车在单行环线上行驶并带跟车防碰撞逻辑,开到挖掘机旁接土、满载后驶往渣土堆卸料,塔吊则先提升再回转吊运物料——整条"挖→装→运→卸"的作业链是连贯的。
- **性能策略明确**:全部几何体程序化生成,采用合并几何 + 实例化渲染,目标稳定 60FPS;提供 `?fps=30` 参数限帧省电。
- **加载兜底**:Three.js r160 依次尝试 jsdelivr、unpkg、cdnjs、esm.sh 四个 CDN,第一个成功者胜出,加载失败时显示友好错误提示。
- **操作方式**:左键拖动旋转、滚轮缩放、右键平移、`R` 键复位视角。

![building-glm53f 效果图](https://picco.de5.net/file/cool-coding/1789389342699_building-glm53f.png)

#### `building-gpt6astra` — 筑间 · 一方工地,一个小世界

gpt6astra 版本(约 773KB 的单文件)走了一条截然不同的路线——它把这个沙盘做成了**带叙事感的交互小品**:

- **文案驱动氛围**:页面以"筑间——一方工地,一个小世界"为题,配合"按自己的节奏""慢慢看,总有新发现""在方寸之间,看一座城市慢慢生长"这样的引导文案,把纯粹的工地模拟升格为一幕"城市生长"的沉浸叙事。
- **分区导览交互**:提供"基坑开挖"等区域按钮,点击可以跳转聚焦到对应功能区,并配有解说文字,例如"渣土车默契接力,把地面之下的每一寸,都变成城市的起点""塔吊在各自的空间里,将材料送到需要它们的地方"。
- **动画细节讲究时序**:渣土车会依次完成装土、运输、侧卸的动作序列;塔吊先提升再回转;板房区"有人核对图纸,有人搬来下一批材料",把工地的生活感也做了出来。
- **完全离线单文件**:全部资源内联,离线、单文件、可交互,双击即开。

## 二、shop-rainning · 雨夜便利店街角

### 主题概述

`shop-rainning` 主题的提示词要求制作一个**雨夜日式便利店街角**微缩场景:第三视角观察,整体像一个可自由拖拽、旋转、缩放的收藏级三维模型,没有任何 UI 界面元素;地面为完整正方形底座,所有元素搭建其上,构图紧凑、层次清晰。

美术上指定了**三渲二(Toon Shading)卡通渲染**、日式二次元动画氛围、清晰轮廓线、湿润的夜景反光,并强调暖色室内灯光与冷色雨夜街景的对比,整体气质"安静、治愈、带一点都市夜晚孤独感但依然温暖"。

场景内容清单相当长:便利店招牌、玻璃橱窗、自动门、屋檐雨棚、自动贩卖机、自行车、雨伞架、路灯、电线杆与电线、路牌、护栏、停车位、排水沟、积水路面、反光斑马线、小巷入口、空调外机……且要求**店内必须充实**——货架、饮料柜、便当区、收银台、咖啡机、关东煮柜台等都要透过大面积玻璃窗清晰可见。动效方面要求持续降雨、屋檐滴水、积水波纹、招牌闪烁、自动门开合、雨水沿玻璃滑落等一整套雨夜细节。

### 模型版本对比

#### `shop-rainning-glm53f` — 雨夜便利店 · 街角

glm53f 版本采用没有界面控件的观赏方式,附带一份详尽的 README:

- **零 UI 的收藏级模型感**:22×22 正方形收藏底座,L 形街角转折,完全遵守"没有任何 UI 界面元素"的提示词要求,只有场景本身。
- **店内内容极其充实**:透过橱窗可见货架商品、饮料柜、便当柜、饭团柜、收银台、咖啡机、关东煮柜台(冒热气)、炸物柜、杂志架、冰淇淋柜、ATM、海报灯箱、后场门;商品使用 InstancedMesh 约 900 个实例渲染。
- **三渲二实现规范**:Three.js r160 + `MeshToonMaterial` 三阶渐变,配合反转法线外壳法描边,轮廓线干净利落;湿润路面用 Phong 高光表现。
- **性能设计 CPU 友好**:默认帧率上限 30FPS(可 `?fps=24` / `?fps=60` 调节),窗口最小化自动降到约 10FPS,像素比上限 1.5,降雨、涟漪、水痕等动效全部由着色器时间驱动,零 CPU 更新。
- **工程化细节**:自带零依赖启动服务器(`node server.mjs`),Three.js 本地化到 `libs/` 目录离线可用,还提供 `?still=1` / `?test=1` 等自动化测试钩子(`__shot()` 截图、`__pick()` 射线拾取等)。
- **彩蛋**:街角还有一只猫。


![shop-rainning-glm53f 效果图](https://picco.de5.net/file/cool-coding/1789389337504_shop-rainning-glm53f.png)


#### `shop-rainning-gpt6astra` — 雨宿り · AMAYORI

gpt6astra 版本采用 Vite + npm 工程结构，包含 `src/` 源码目录、`vite.config.js` 和生产构建流程，标题为**雨宿り（AMAYORI）**。页面提供一条**可收起的设置条**，收起后可以专注观看场景：

- **画质体系完整**:节能/平衡/精细三档预设;帧率上限 6–60 FPS 共六档;渲染精度 65%–135%;阴影质量 512–2048 可切;积水反射分节能(384px/500ms)/标准(768px/240ms)/精细(1024px/125ms)三档;雨量 0–100% 无级调节;还有画面亮度、灯光辉光等参数。画质设置保存在浏览器本地,刷新后恢复，视角与暂停状态不持久化。
- **无障碍与能效意识**:页面隐藏后暂停渲染;系统开启"减少动态效果"时自动降至 12 FPS、减少雨量并关闭招牌闪烁——这在一次性生成的项目里相当少见。
- **场景规模可观**:双面玻璃便利店、日文灯箱、四组货架、三组饮料冷柜、**408 件商品**、便当与饭团陈列、盲道、分类垃圾桶、屋顶设备等,静态模型按材质合并,雨线与波纹走 GPU 动画。
- **贴图全部本地 Canvas 绘制**,无任何外部素材或字体请求。
- **操作**:左键旋转、滚轮缩放、右键平移,双击或 Home 复位,聚焦后还支持方向键与加减键微调,移动端双指手势齐全。

![shop-rainning-gpt6astra 效果图](https://picco.de5.net/file/cool-coding/1789389337944_shop-rainning-gpt6astra.png)

#### `shop-rainning-opus5` — 雨夜便利店(Rainy Night Convenience Store)

opus5 版本是一个单文件实现，采用 Three.js r160 与 OrbitControls，观看时通过 CDN 加载运行库，需要联网。它的参数控制集中在右下角齿轮面板中：

- **⚙ 控制面板**:右下角齿轮按钮呼出设置面板,提供雨滴密度、雨滴速度、雨滴大小三组滑杆,可以对雨效做像素级调校——想看毛毛雨还是暴雨,拖一下就好。
- **画质选项**:可调整帧率上限；阴影质量分低/中/高/超高四档(512/1024/2048/4096)，抗锯齿可开关，一键“重置默认”恢复初始状态。
- **场景分区清晰**:代码按底座、便利店主体、街道元素、照明系统、雨效果、大气效果等模块组织,便利店内有货架系统(4 排)、收银机屏幕等细节。
- **动效齐全**:雨滴下落、积水波纹动画、积水区域反光、自动门、雨棚等雨夜要素一应俱全。

![shop-rainning-opus5 效果图](https://picco.de5.net/file/cool-coding/1789389339040_shop-rainning-opus5.png)

#### `shop-rainning-ds41f` — 雨夜便利店街角

DS41F 版使用 Vite 与 Three.js（依赖为 `^0.169.0`），将四级卡通明暗、外壳描边和暖色店面灯光结合在一个正方形沙盘中。L 形道路、抬高的人行道、绿白斜纹雨棚、玻璃幕墙、两辆自行车和下沉小巷形成紧凑街角；店内可见货架、饮料柜、便当柜、冷冻柜、L 形收银台、咖啡机、关东煮和杂志架。

- **雨夜细节**：雨丝、屋檐滴水和积水波纹使用 GPU 动画，玻璃水痕、灯箱闪烁、自动门开合与交通灯循环共同营造持续变化的夜景；招牌、海报和商品贴图均由 Canvas 绘制。
- **可收起的设置条**：左上角集中提供帧率、阴影、渲染倍率、轮廓线、积水反射、湿润高光、雨量和动效开关，默认上限 40 FPS。
- **四种取景**：左键旋转、右键平移、滚轮缩放，按 `1`–`4` 切换街角主视角、店面正视、俯视模型和小巷侧视，`H` 收起或展开设置条。
- **运行方式**：在 `shop-rainning-ds41f/` 执行 `npm install`、`npm run dev`，默认打开 `http://127.0.0.1:5187/`；`npm run build` 生成 `dist/`，`npm run preview` 默认使用 4173 端口。可用 `?fps=20` 限帧、`?still=1` 冻结动画，完整参数见该目录的 README。

## 三、gardon · 湖畔花园的四季来信

### `gardon-gpt6astra` · A Garden in Time

### 主题概述

`gardon-gpt6astra` 的成品标题是**湖畔花园的四季来信**(A Garden in Time)。它不是单纯摆放几棵树的静态模型,而是一座放在窗边木桌上的离线体素花园:木质托盘里有湖泊、小岛、书屋、玻璃温室、咖啡屋、桥、植物、行人和一只会沿季节变化的小船,窗外的光线则把它和真实房间联系起来。

这个版本把"四季"做成了真正连续的时间系统。默认约 480 秒走完一年,春天有花和新叶,夏天有繁茂的植物与萤火,秋天出现落叶和薄雾,冬天会下雪、结霜并冻结湖面;昼夜独立流转,灯光、天气、环境音和生物活动也会随时间改变。小船会在湖面结冰前靠岸,解冻后重新出航,季节切换不会突然跳帧。

### 交互与工程特点

- **视角控制**:左键拖动环视,右键平移,滚轮缩放,支持俯瞰、复位和纯净观景模式;触屏支持拖动与双指缩放。
- **时间控制**:可以暂停整个花园,拖动季节刻度,或使用"流年 / 时节 / 风雨"三枚实体旋钮调节循环速度、季节进度和天气强度。
- **持续观看**:提供节能模式,页面隐藏时自动暂停;还可以开启由 Web Audio API 合成的风声、水声和鸟鸣。
- **离线实现**:Three.js r160、几何体、材质、贴图、环境音和动画全部内联或程序化生成,验证构建没有外部资源请求。
- **规模与连续性**:植物实例约 7,363 个,雪实例约 1,294 个;季节参数经过全年 28,800 个采样点验证,周期首尾和速度连续。

![gardon-gpt6astra 效果图](https://picco.de5.net/file/cool-coding/1789389339376_gardon-gpt6astra.png)

### `gardon-ds41f` · Letters of the Four Seasons

DS41F 版同样把四季花园放在橡木桌上，内嵌 Three.js r160，以起伏地形、溪流、湖泊、小岛、书屋、玻璃温室、亭子、木桥和码头组成一座可环绕观看的微缩景观。植物、花朵、蝴蝶、飞鸟、萤火、落叶、雨雪、薄雾与湖冰分别随季节变化，日照时长和昼夜光照同步调整；小船会在湖面冻结前返回泊位。

- **四季控制**：默认约 480 秒走完四季，可调为 120–900 秒；点击或拖动季节进度条，或拖动桌上的三枚铜旋钮，调整流速、季节与天气，也可以暂停时间。
- **视角与画质**：拖动环视、滚轮缩放，支持自动环绕；设置面板提供省电／均衡／精细预设，30–120 FPS 或不限帧、渲染比例、阴影、粒子密度、曝光、柔光及闲置暂停选项，默认上限 60 FPS。
- **单文件运行**：运行库、场景几何与程序化贴图集中在一个 `index.html` 中，可双击离线观看，也可通过本地静态 HTTP 服务打开，无需 npm 安装或构建。

## 四、lego-gpt6astra · 层间 STACKED
